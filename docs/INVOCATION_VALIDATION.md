# 唤出手势验证（2026-09-18）

本轮实现可即时保存的晃动灵敏度、用户示范校准和双击 Command 唤出。默认灵敏度 50%，保留旧版 `shakeEnabledV2` 开关；两种手势分别开启或关闭。

## 自动验证

`swift test`：44 项通过（26 项原有测试、14 项手势测试、4 项设置及校准控制器测试）。

- 灵敏度改变所需幅度和时间窗口，高频鼠标小于 2 点的事件也可累积识别。
- 排除轻微抖动、单向移动、拖拽、间隔过长的转向；保留 3 秒晃动冷却。
- 示范结果能按原幅度与速度再次触发；仅编码幅度中位数、4 次转向用时和示范时间。
- 暂停采集时仍可校准；示范期间不唤出菜单。取消、非法结果保留旧设置；恢复默认清除校准但保留两种唤出开关。
- 参数立即保存，重新初始化控制器后恢复；测试使用独立 UserDefaults suite，不改用户真实偏好。
- 左右 Command 分别可用，要求同侧两次完整短按。组合键、其他修饰键、交叠的左右 Command、长按、慢速连按、中间插入其他输入及冷却期均不会误触发。

`./scripts/build-app.sh release`：发布构建使用固定本地自签名身份；校验 Bundle ID 与证书根要求一致，且指定要求不绑定单次构建的 `cdhash`。

## 实际界面验证

- 新版已安装到 `~/Applications/SmartApp.app`，旧版保留在 `~/Applications/SmartApp.backup.20260918-001333.app`，恢复更新前正在进行的采集。
- 「采集设置 → 唤出方式」显示两种开关、灵敏度滑块、示范与恢复按钮。
- 滑块实测从 50% 调到 77%，随后恢复 50%；UserDefaults 中核验为 `0.5`。
- 示范显示准备阶段、倒计时和转向进度；未完成时超时退出，保留原灵敏度。
- 更新后系统最初将辅助功能授权判为失效，界面正确显示权限提示。全局按键监控依赖辅助功能授权，见 [Apple NSEvent 文档](https://developer.apple.com/documentation/appkit/nsevent/addglobalmonitorforevents(matching:handler:))。
- 经用户确认并完成 Touch ID 验证后，移除失效条目、重新添加当前安装路径的 SmartApp；实际应用进程最终写出 `accessibility=true`、`collecting=true`，授权与采集均已恢复。

自动化工具不能单独发送修饰键，也没有无按键的鼠标移动接口，因此本轮未通过电脑控制工具伪造完整的实际 Command 双击或鼠标示范。手势序列、校准成功与保存由自动测试覆盖；实际设备的手感需由用户在「开始示范」中确认。

## 数据边界

`InputMonitor` 仅把一次唤出回调交给原有菜单入口；不读取键盘文字，不向采集器传递输入事件。鼠标坐标、按键时序仅用于内存中手势判断。校准参数进入应用偏好，未新增行为数据表或训练字段。三个入口沿用同一目标观测和推荐会话记录。
