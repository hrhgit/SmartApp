# 不确定使用代价时，如何统一评价

这是研究结论、当前共同指标与协议建议，不自动选定新的频率偏好或上线策略。匹配收益已按用户新约定统一为精确 1、正确首页回退 0.6、错误 0；当前评分实现仍只有 `scripts/evaluation_contract.py`。

## 结论

可以统一评价的对象、样本、时间边界、动作语义和代价函数，但不能仅靠行为频率识别用户真正的损失偏好。代价没有确定时，保留共同基准和偏好敏感性分析，比选一个有利于新策略的计分器更可靠。如果不同合理代价下胜负相反，就报告取舍；没有义务制造唯一赢家。

“统一”并不要求所有情景下的错误都一样贵。可以令公共代价为 `C_ref(x, action, truth)`，只要相同截点、相同动作和真实结果，对所有策略使用同一个函数。不能令它变成每个策略自己的 `C_model`。

## 以 TopK 和目标位置形成综合分

用户希望综合评价反映实际目标与推荐顺序的差，并明确精确命中收益 1、正确首页回退收益 0.6。当前加入一个线性位置折扣的共同指标：先令每项匹配收益 `q = 1 - decision_loss`，然后定义：

`U_j = max(q_1, ..., q_j)`，只读取实际输出的前 j 个位置；空前缀收益为 0。

`RankScore@4 = (U_1 + U_2 + U_3 + U_4) / 4`。

它是 Top1 至 Top4 最佳收益的平均。在每条样本只有精确命中或未命中时，等于 `(Hit@1 + Hit@2 + Hit@3 + Hit@4) / 4`；真实目标排第 r 位对应 `1 - (r-1)/4`，前四项没有目标则为 0。

| 唯一匹配所在位置 | 精确命中 | 仅正确首页回退 |
|---|---:|---:|
| 1 | 1.00 | 0.60 |
| 2 | 0.75 | 0.45 |
| 3 | 0.50 | 0.30 |
| 4 | 0.25 | 0.15 |
| 前四项未匹配 | 0 | 0 |

首页与具体页面同时存在时，每个前缀只取最好的一项。例如首页第 1、具体页面第 4，得分为 `(0.6+0.6+0.6+1)/4 = 0.7`，不把首页与具体页面当成两次独立需求加分。真实目标本来就是首页，则首页属于精确命中，收益为 1。错误具体会话即使在同服务内仍为 0；历史服务接受 TopK 继续另列，不能把它的宽松归并直接用于此综合分。

此指标对所有策略使用相同的 4 个实际输出位置、相同合法样本和相同匹配规则，不读取模型的内部频率代价。不将未命中样本排除，也不以全词表里的排名替换实际菜单。它评价可用菜单的覆盖及位置，不声称位置差就是已测得的时间成本。线上真实选择可能受展示顺序影响，不能只用选中了菜单的样本证明整体推荐效果；当前离线仍使用统一审查的后续目标标签。

线性折扣是贴近“名次差”的当前实现选择，不是已测定的人类浏览模型，也不是 NDCG 或 MRR 的改名。保留 Top1/Top2/Top4 明细及原有 MRR 诊断，避免综合分掩盖覆盖下降。本次只补充统一指标并重算冻结预测，不据此重新选择、训练或上线模型。

## 分开评价概率与行动

| 层次 | 回答的问题 | 共同评价方法 | 不能据此声称 |
|---|---|---|---|
| 概率预测 | 对将发生的目的地及其不确定性估计得怎样 | 固定结果空间上的 Brier score、log loss，加校准诊断 | 概率好就一定更省操作 |
| 菜单排序 | 实际前几个位置是否包含目标 | 同一合法有证据集，精确与服务接受 Top1/2/4 | 服务接受命中等于精确会话命中 |
| 决策代价 | 给出的动作对真实目标造成多大损失 | 同一公共代价函数、同一频率参考和分母 | 用自己的损失给自己打分就算胜出 |
| 实际使用 | 是否帮助用户更快到达所需目的地 | 有可比对照的实际结果；另行设计 | 自然导航时间等于推荐节省时间 |

Brier 和 log loss 属于严格适当评分规则：在相同结果定义下，真实概率分布在期望上得到最优分数。它们可用来比较概率学习器，不需要先选择全局频率还是情景频率作为错误代价。但它们不保证任何具体代价下的有限样本排名一致。[Gneiting & Raftery, 2007](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

本次 fixed、global_frequency、context_frequency 共用同一概率分布，只改变行动。因此三者的概率分数必然相同，不能用 Brier/log loss 选出最佳决策策略。原排序模型也未校准，最小估计风险不是已验证的真实风险。

未来跨概率模型比较需固定每个截点可知的公共具体目标空间及未知桶。若不同模型可以自行把难预测目标归入“其他”，概率分数将不可比。已知／未知概率诊断也不能替代具体目标 TopK。

## 频率的两个作用不能混淆

频率首先描述事件出现的可能性：自然分布上的普通平均损失，已经让频繁出现的目标贡献更多次。若目标 A 出现 80 次、B 出现 20 次，普通平均已经按 80:20 累计；再让每次损失按 4:1 加权，在两类错误率相同时，两类总损失贡献变成 16:1。这可以表达“常用目标每次漏掉也更可惜”，但这是额外价值偏好，不是提高估计客观性的必需步骤。

当前用户已确认偏好的方向是“常用目标漏选更可惜”，尚未确定强度、全局／情景参考及跨情景单位。历史频率不能独自回答这些问题，也不能证明实际找回代价是多少。若想评价实际操作负担，更直接的外部量应是找回所需额外操作或时间，但现有自然到达数据不足以可靠识别推荐的因果收益。

现有频率实验将每个截点的结果权重归一化为均值 1。对同一截点，将所有代价乘相同正数不影响最小风险动作，却会改变跨截点总分中这个情景的分量。因此不仅要固定频率算法，还要固定评价的跨情景单位与归一化。未来不同模型若有不同词表，不能根据各自词表重新归一化评价权重。

## 当前可执行的统一协议

1. 保留已约定的合法有证据集为主分母，先报合计命中数、总数和覆盖率，再报新旧、证据分组及全部合法样本。合法性审查不读取预测结果，不因目标低频、未知或不在模型词表中删除样本。
2. 继续给出共同的精确与服务接受 Top1/2/4，并报告上述综合排名分；保留既定 Top4 比较与当前 Top2 优化关注，不改成仅按 Top1 代价选优。当前固定实际损失为精确 0、正确首页回退 0.4、错误 1。
3. 频率偏好另给一张交叉评分表：固定、全局频率、情景频率三列，每列对全部策略使用相同权重。策略内部可以用不同的代价决策，评测时仍然全部过同一套公共指标。
4. 每列权重只读取截点前已成熟的独立行为，平滑、时间范围、情景相似性、未知目标处理、权重归一化均提前冻结。结果发生后只查表取真实目标的权重，不利用结果调整频率或样本。
5. 记录公共评分代码、样本、频率参考和权重哈希。所有旧预测在同一入口重算；对照只能比较同一列，不把一行的固定分与另一行的加权分比较。
6. 不同偏好下出现权衡时，先报告非劣方案及胜负翻转范围。将来需要单一部署判据时，先确定可接受的取舍（例如保护常用目标时允许多少整体 Top2 回退），再冻结规则验证新时段；不从当前结果反推最有利的阈值。

同一协议可以长期不变，历史频率数值仍可按明确的因果更新规则随新行为变化。冻结的是定义及更新方法，不是要求永远使用某一天的计数。

## 本次敏感性研究的方法

复用冻结的预测，对所有方案用公共入口重算三个实际损失：

`R_fixed = mean(L)`

`R_global = sum(w_global * L) / sum(w_global)`

`R_context = sum(w_context * L) / sum(w_context)`

然后描述两条评价路径：`R_alpha = (1-alpha) * R_fixed + alpha * R_frequency`，`alpha` 从 0 到 1。每个端点先用自己的公共分母归一化，因此这些路径只表示两种评价目标的相对偏重，不是未经归一化代价的直接混合，更不是模型融合比例。程序将路径上的加权实际损失再次交给公共评分入口计算，校验其与线性公式一致。

给出所有策略之间精确交点和最低损失区间，不按“赢的区间更长”选择策略。那样等价于额外假设用户对 alpha 的分布；均匀平均、最坏情况或最小最大遗憾也分别加入了额外偏好，均不能自动消除价值判断。非劣只相对于明确列出的指标成立，不代表所有使用场景都好。

这种“展示在哪些代价范围内更好”的思路来自成本曲线研究；原论文主要讨论二分类。这里使用共同多目标损失列的线性敏感性分析，是针对本项目的扩展应用，不是将二分类公式直接套到层级推荐。[Drummond & Holte, 2006](https://webdocs.cs.ualberta.ca/~holte/Publications/mlj2006.pdf)

复现：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 research/algorithm-research/scripts/study_evaluation_preferences.py \
  --source '<已有 bayes-frequency 私有 run>' \
  --output '<新的私有 training run>'
```

同时报告权重集中度 `1/sum(normalized_weight^2)` 和按会话配对的逐一剔除诊断。集中度等效条数不是独立样本量；逐一剔除范围不是置信区间。既有数据已反复用于研究，不能把当前赢家或交点当作新时段的确定规律。

## 最终用户收益需要独立验证

Top1 代价衡量第一项，Top2/Top4 衡量菜单机会，两者都保留。菜单内存在一个好选项不意味着用户一定选中它；菜单最小损失假定了理想选择，也未计入寻找、比较、点击与执行失败的负担。若后续要以“更省时间”为统一用户收益，需单独定义可观测结果和比较设计。

已有自然行为可评预测；推荐产生的反馈则受展示和选择影响。反事实评价通常要求记录策略概率、充分的动作覆盖和相应假设，不能从当前没有这些条件的自然到达日志构造无偏推荐收益。[Swaminathan & Joachims, 2015](https://proceedings.mlr.press/v37/swaminathan15.html)

这不是扩大采集的授权：继续遵守未选择菜单不持久化、不关联随后自然导航的约定。此研究不修改采集和运行时，也不新增键盘、点击正文或页面正文数据。
