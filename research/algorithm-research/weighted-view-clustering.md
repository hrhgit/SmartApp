# 分组加权的情景聚类：概念与候选方法

当前实验已按后续决定收敛为“有序目标序列，只启用长度 1（当前界面）”，见 `scripts/evaluate_ordered_current.py`。当前与向前回溯的历史统一为相同类型的不同长度；下文的无序频次和多视图加权保留为此前研究的备选方案，不是本轮启用的模型。

下文是此前提出的备选实验设计，其中的加权方案尚未实施，也没有对应的新准确率结果。前一轮参数网格只给前台分配状态部分的 0% 或 30%；在历史占 20% 时，前台名义总权重最高为 24%。因此，前一轮没有检验“当前目标为主、近期上下文其次、后台库存较弱”的设定。

## 先区分三种输入

| 输入组 | 含义 | 表示与比较 |
|---|---|---|
| 当前前台目标 | 预测时正在使用的具体页面、窗口、目录或应用 | 独立保留目标及其层级；精确目标、页面路径/站点与所属应用可提供不同粒度的匹配 |
| 近期活动上下文 | 最近若干次已观察到达中在使用什么 | 可以用目标访问频次；顺序版另存位置，无序版只累加次数 |
| 后台库存 | 当时观察到仍打开的应用、窗口、标签页、目录窗格等 | 按来源比较集合/加权集合；缺失来源与已确认空集合分开 |

当前目标属于输入，但不应仅被埋进近期访问计数里。将近期历史表示为无序频次，并不意味着丢掉“当前在哪儿”。后台对象出现不计为一次访问，也不产生后续标签。

“近期频次”中的“近期”只规定取样窗口。已有频次版取最近 8 次到达（包含当前到达），重复目标累加；不编码第几步，不随距今远近衰减。“按最近访问排序”则根据每个目标最后访问时间排序，是另一个基线。类内下一步频次又是第三个概念：它统计过去属于该类的情景后来去了哪些目标，作为输出排序依据。

用最近 5 次访问举例，`A → B → A → D → C` 与 `A → D → A → B → C` 的无序频次相同：A 为 2，B/D/C 各为 1，当前目标都为 C。两条有序路径不同；排除当前 C 后，最近访问排序的第一项分别是 D 和 B。

## 对应的研究方向

- **多视图聚类（multi-view clustering）**：同一个情景有多组描述，分别处理后再融合。它是方法族，不是单个算法；可在特征、相似度、核或聚类结果层面融合。[多视图聚类综述](https://arxiv.org/abs/1712.06246)
- **混合类型数据聚类**：同时处理类别、数值、二元、序数等变量。Gower 距离按变量类型计算差异并支持变量权重，得到的距离矩阵可以输入 PAM/K-medoids。[Gower/daisy 官方文档](https://stat.ethz.ch/R-manual/R-devel/library/cluster/html/daisy.html)、[PAM 官方文档](https://stat.ethz.ch/R-manual/R-devel/library/cluster/html/pam.html)
- **K-prototypes**：将 K-means 的数值部分与类别部分的失配代价结合，适用于数值和类别混合的表格。当前数据还含动态集合、路径层级与稀疏频次，仅靠把每组当成一个普通类别字段不足以保留这些结构。[Huang 原始论文](https://cse.hkust.edu.hk/~qyang/Teaching/537/Papers/huang98extensions.pdf)

本项目同时存在“不同来源的描述”和“不同数据类型”，因此可以组合这两种思路。

## 建议比较的两种实现

第一种沿用分组归一化的加权 KMeans，先只改变权重范围，检查前一轮的问题是否来自当前目标被弱化。拼接向量时，三个归一化特征组分别乘以权重的平方根，使平方欧氏距离中各组的系数为对应权重。后台还需保留来源质量折扣，不能在缺失后重新归一化成完整证据。

第二种用**分组加权距离 + K-medoids/PAM**。每组选择适合的数据差异：当前目标用层级匹配，近期计数用频次向量差异，后台用集合差异。各组先转换到可比尺度，再融合：

`D = α × D当前目标 + β × D近期上下文 + γ × D后台库存`

起始假设为 `α > β > γ`、三者和为 1。例如先验证 `50/35/15`、`60/30/10`、`70/20/10`，这些比例不是实测最优值。组权重控制整组贡献，不能让更多后台标签页或更多 one-hot 列自动获得更高总权重。

K-medoids 的代表点来自实际历史情景，方便解释每类与检查典型案例；它可以接受自定义距离矩阵。PAM 的批量拟合有计算和存储成本，不应把它称为免费的在线聚类；类别固定期间，下一步计数可以在标签成熟后逐条更新，类别更新则另行处理。[PAM 官方文档](https://stat.ethz.ch/R-manual/R-devel/library/cluster/html/pam.html)

这不是直接套用未经修改的 Gower：其默认缺失处理会按可观测变量重新计算分母。本项目仍需保留各来源缺失信息与证据覆盖门槛，防止只观察到少量相同字段就被判作充分相似。URL、目录和类别 ID 也不能当连续数字直接计算距离。

## 聚类相似不等于下一步相同

特征组权重决定情景如何分组；推荐层还需要检验类别及当前目标条件下的后续行为是否集中。可以比较类内整体频次与“类 + 当前目标”条件频次。提高前台权重不会自动解决候选缺失、稀疏支持或同频率平局。

词表、尺度和类别只能由当时已知的早期输入拟合；权重按后续行为预测的验证表现选择，不能只追求几何上类别分得好看。现有后期测试已经多次查看，仍只能用于探索；关于稳定优势的结论需要后续自然产生的数据。
