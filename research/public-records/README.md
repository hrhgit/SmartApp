# Public research records

These are edited summaries prepared from local work logs for this public repository. They keep the research questions, implementation decisions, and high-level conclusions while omitting personal destination histories, exact metrics derived from private activity, local database and report paths, process IDs, and installation backup details. They are not copies of the original logs; the originals remain local.

Research source code and authored analysis notes are kept under `../algorithm-research/`. Build products, caches, private exports, model state, and detailed run outputs are not included.
