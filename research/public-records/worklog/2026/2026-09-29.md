# Public work record — 2026-09-29

## Scope

Continued research on frontmost-destination history, observation gaps, hierarchy-aware prediction, and incremental learning. Work also covered recording stability, memory use, safe restart behavior, and keeping data writes and model updates consistent with the existing privacy boundary.

## Findings

The research separated confirmed arrivals from inferred path support, and required every model input to use only evidence available at its prediction time. Tests and replay checks were used to compare shared inputs and feedback rules. Results from private activity did not establish a reliable accuracy improvement across models, so the work kept those results as research evidence rather than presenting them as general product performance.

## Privacy note

Private database contents, personal destination or browsing details, live-use counts, process identifiers, installation paths, and local backup/report locations are omitted. The corresponding original work log remains local.
