# Public work record — 2026-10-10

## Score-margin selection

Added a separate score-margin calibration method for choosing a variable number of recommendations. It uses mature feedback from frozen predictions, leaves destination matching to the shared rule, and distinguishes unavailable correct entries from entries excluded by the display limit. The evaluation goal and display cap are configuration choices, not measured guarantees.

## Clipboard and FileRecall entry

Added an independent clipboard history and a fixed FileRecall entry to the existing menu. Clipboard records remain separate from destination history, training, and export. Directory and file destinations remain in their dedicated lookup flow. The ordinary application, window, and webpage recommender was not claimed to use clipboard meaning.

## Privacy note

Public validation statements refer to synthetic inputs and code checks. Personal clipboard contents, live destination history, local model/runtime state, process identifiers, and build logs are omitted.
