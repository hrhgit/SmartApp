# Public work record — 2026-09-28

## Scope

Studied hierarchy-aware destination ranking and fallback actions, including URL and folder ancestors that can be derived from a previously known, reopenable destination. Updated the shared evaluation rules to keep path-level usefulness separate from an exact destination match, and tightened the time boundary for what a prediction may use.

## Findings

Adding path-level actions increased useful-entry coverage in some comparisons, but heavier ancestor scores pushed exact destinations down for some models. The evidence supported reporting path success and exact matches separately, keeping one shared scoring path, and checking the same fixed sample members before claiming a change helped.
